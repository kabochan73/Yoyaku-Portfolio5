# 01. 要件

## 1. 施設

| 項目 | 値 |
|---|---|
| 名称 | FUTSAL PARK（屋内人工芝フットサルコート） |
| コート数 | 1面 |
| 営業時間 | 10:00〜22:00（1時間単位の枠: 10時枠〜21時枠の12枠） |
| 料金 | 平日 / 土日で時間単価が異なる（初期値: 平日 4,000円/h、土日 5,000円/h）。管理者が変更できる |
| 定休日 | 曜日で指定（初期値: 月曜）。複数曜日可。管理者が変更できる |
| 臨時休業日 | 日付で指定。管理者が登録・削除できる |
| 支払い | 現地払いのみ |
| 貸し出し | ボール・ビブス無料 |

- 祝日は平日料金（祝日の判定はしない）
- 施設情報（名称・電話番号・住所・メールアドレス）は1か所で管理し、画面とメールで同じ値を使う

## 2. ユーザー

| ロール | できること |
|---|---|
| ゲスト | 施設情報・空き状況の閲覧、会員登録、ログイン |
| 会員（`user`） | 予約、自分の予約の一覧・キャンセル、プロフィール編集 |
| 管理者（`admin`） | 全予約の閲覧・キャンセル、電話予約の代理登録、料金・定休日・臨時休業日の設定、会員検索、プロフィール編集 |

- 管理者アカウントはシーダーで作る（画面からは作れない）
- 会員登録で作られるのは常に `user`

### 会員登録・プロフィール

| 項目 | ルール |
|---|---|
| 名前 | 必須、20文字以内 |
| メールアドレス | 必須、メール形式、255文字以内、一意 |
| パスワード | 必須、8文字以上、確認入力と一致 |

- 登録と同時にログイン状態になる
- プロフィール編集で名前・メールアドレスを変更できる。パスワードを変えるときは現在のパスワードが必要

## 3. 予約ルール

| # | ルール |
|---|---|
| B1 | 予約は1時間単位。開始・終了は正時 |
| B2 | 利用時間は 2〜4時間 |
| B3 | 営業時間（10:00〜22:00）内に収まること |
| B4 | 予約できるのは今日から1か月後の同日まで（その日を含む）。1か月後に同じ日が無いときはその月の末日（1/31 → 2/28） |
| B5 | 開始時刻が現在時刻より後であること（開始時刻ちょうどは不可） |
| B6 | 定休日・臨時休業日は予約できない |
| B7 | 他の確定済みの予約と時間が重ならないこと。同時に申し込まれても二重予約にならない |
| B8 | 会員は1日1件まで（確定済みの予約が同じ日にあれば不可）。同時に申し込まれても破れない |

| B10 | 予約者名は会員の名前（予約時点の名前を保存） |

| C2 | キャンセルできるのは、確定済みで開始前の予約だけ |

| C4 | キャンセル料は取らない。当日でも開始前ならキャンセルできる |

## 5. 利用規約（トップに表示）

- ご予約のキャンセルは、ご利用開始時刻までにマイページから行ってください。キャンセル料はかかりません。
- コート内での飲食（フタ付きの飲料は可）、喫煙は禁止です。
- 施設・備品を破損・紛失された場合は、実費をご請求させていただきます。
- その他、スタッフの指示に従ってご利用ください。

## 6. 管理者の操作

### 6.1 予約カレンダー

- 週単位（月曜始まり）のカレンダーで予約状況を見る。予約済みの枠には予約者名を表示する。電話予約には ☎ を付ける
- 過去は3か月前まで遡れる。未来は制限なし
- 定休日・臨時休業日・期間外の日も、予約が残っていれば予約者名を表示し、詳細の確認・キャンセルができる。予約の無い受付外の日には理由（定休日・臨時休業日など）を表示する
- 予約済みの枠を選ぶ → 予約の詳細（予約者名・日時・料金）→ キャンセルできる
- 空き枠を選んで電話予約を代理登録できる
  - 時間帯の選び方はトップのカレンダーと同じ（開始 → 終了の順に選ぶ。[7.1](#71-トップの週間カレンダー)）。終了を選ぶと、予約者名を入力するダイアログを出す
  - 電話予約は会員と紐づかない
  - 会員の予約と同じルール（B1〜B7、B9）を当てる。B8（1日1件）だけは当てない
- 管理者が会員の予約をキャンセルしたら、会員にキャンセルメールを送る

### 6.2 料金設定

- 平日 / 土日の時間単価を変更する（0円以上の整数）
- 変更は、これから作られる予約にだけ効く（既存の予約の金額は変えない）

### 6.3 定休日設定

- 曜日を複数選んで保存する（すべて外すと定休日なし）
- 定休日にした曜日の既存の予約はそのまま残す。管理者が個別に対応する

### 6.4 臨時休業日

- 日付と理由（任意、255文字以内）を登録・削除できる
- 登録できるのは今日以降の日付だけ。一覧も今日以降だけを表示する
- 定休日にも登録できる（後で定休日を外しても、その日は休みのまま残る）
- 同じ日を二重に登録することはできない
- 登録しようとした日に、確定済みでまだ開始していない予約があるとき:
  1. 件数を示して確認を求める
  2. 管理者が承認したら、それらの予約をすべてキャンセルして休業日を登録する（全部成功するか、全部失敗するか）
  3. 会員の予約には「施設都合キャンセル」メール（理由入り）を送る
- 当日を休業日にするとき、開始済み（利用中・利用済み）の予約はキャンセルせずに残す
- 削除するときは確認を挟む。削除しても、キャンセルした予約は戻らない

### 6.5 会員検索

- 名前またはメールアドレスの部分一致で会員（`user` ロール）を検索する
- 結果は最大20件。名前・メールアドレス・確定済みの予約の件数を表示する

## 7. 画面

| パス | 画面 | 閲覧できる人 |
|---|---|---|
| `/` | トップ（Hero・施設情報・週間カレンダー・利用規約） | 全員 |
| `/login` | ログイン | ゲスト（ログイン済みなら管理者は `/admin`、会員は `/` へ） |
| `/register` | 会員登録 | ゲスト（同上） |
| `/mypage` | 今後の予約一覧・キャンセル・プロフィール設定 | 会員（未ログインは `/login`、管理者は `/admin` へ） |
| `/admin` | 予約カレンダー・料金・定休日・臨時休業日・会員検索・プロフィール設定 | 管理者（未ログインは `/login`、会員は `/` へ） |

### 7.1 トップの週間カレンダー

操作:

1. 空き枠を選ぶ → 「開始」になる
2. 同じ日の、開始から2〜4枠目で、間がすべて空いている枠が「終了候補」として強調される
3. 終了候補を選ぶ → 予約内容の確認ダイアログ（日付・時間・利用時間・合計料金）
4. 「予約する」→ 予約完了。「予約しました」とマイページへのリンクを出す
   - 未ログインなら「ログインして予約」でログイン画面へ移る。選んでいた枠は引き継がない（ログイン後にもう一度選ぶ）
5. 開始を選んだ後に、終了候補でない別の空き枠を選ぶと、そこが新しい開始になる。空きでない枠を選ぶと選択を解除する
6. 開始に選んだ枠をもう一度選ぶと選択を解除する

表示:

- グリッドの上に、次に何をすればよいかの案内を1行出す
- 週は月曜始まり。今週より前には戻れない。予約できる最終日を含む週まで進める
- 枠の表示: 空き / 予約済（誰の予約かは出さない）/ 受付外（定休日・臨時休業日・過ぎた時間・期間外）
- ページを開いたときは、その時点の最新の空き状況を表示する（前に作った古い空き状況は出さない）
- 表示した後は、他の人の予約・キャンセルを最大60秒遅れで反映する。自分の予約・キャンセルはすぐ反映する
- 空き状況の取得に失敗したら、エラーと再読み込みのボタンを出す（全部の枠を受付外に見せない）

### 7.2 マイページの予約一覧

- 今日以降の確定済みの予約を、日付・開始時刻の順に表示する
- 開始前の予約にはキャンセルボタンを出す。開始済みの予約は「ご利用中」「ご利用済み」と表示し、キャンセルボタンを出さない

### 7.3 ログイン・ログアウト後の移動先

| 操作 | 移動先 |
|---|---|
| ログイン | 管理者は `/admin`、会員は `/` |
| 会員登録 | `/` |
| ログアウト | `/` |

## 8. メール

| メール | 送るタイミング | 宛先 |
|---|---|---|
| 予約完了 | 会員が予約したとき | 予約した会員 |
| 予約キャンセル | 会員がキャンセルしたとき / 管理者が会員の予約をキャンセルしたとき | 予約した会員 |
| 施設都合キャンセル | 臨時休業日の登録で予約がキャンセルされたとき（理由入り） | 予約した会員 |

- 電話予約にはメールを送らない
- 本文: 予約者名、予約日（曜日付き）、時間、料金、施設の連絡先

## 9. データ保持

- 予約日が3か月より前の予約は毎日削除する（管理画面で遡れる範囲とそろえる）
- 会員が削除されても予約は残す（予約者名を保存しているため、誰の予約だったかは分かる）

## 10. 非機能要件

| 項目 | 要件 |
|---|---|
| 日時 | 日付と時刻はすべて日本時間（Asia/Tokyo）で判定する。「今日」「開始前」「1か月後」などのルールはこれが前提 |
| 回数制限 | ログイン・会員登録は、IP とメールアドレスの組ごとに 5回/分まで（パスワードの総当たりを防ぐ） |
| 画面幅 | スマホ幅（375px）でも崩れない。ページ全体が横にはみ出さない |
